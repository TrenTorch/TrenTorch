# Hypothesis Function

Implement the linear regression hypothesis: a straight line through weight `w` and bias `b`.

## Task

Implement `predict(x, w, b)`:

- `x` is a NumPy array of any shape.
- `w` and `b` are scalars.
- Return the hypothesis output, elementwise.

## Example

```python
>>> predict(np.array([1.0, 2.0, 3.0]), w=2.0, b=1.0)
array([3.0, 5.0, 7.0])
```
